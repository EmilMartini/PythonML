# PythonML

A very small neural network written from scratch in Python, with no numpy or other libraries.

- `matrix.py`: a minimal matrix class (multiply, transpose, element-wise operations).
- `neuralnetwork.py`: one hidden layer, sigmoid activation, training by backpropagation.
- `program.py`: trains a 2-2-1 network on XOR for 10,000 iterations and prints the four predictions.

Run it with `python program.py`. It clears the screen with `cls`, so it expects Windows.
